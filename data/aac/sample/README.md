# AAC Sample

A stratified, scrubbed slice of AgentArtifactCorpus. 327 files spanning 34 strata (file family × language). Generated by [`../scripts/make_sample.py`](../scripts/make_sample.py) from the full 396,934-file corpus.

## What this is for

- **Reviewers** can reproduce the headline experiments without obtaining the full corpus. The compaction, decomposition, classifier-ablation, and SafetyMargin experiments accept `--data-dir data/sample` and converge to within sampling variance of the full-corpus numbers reported in the paper (TypeCompact constraint preservation stays at 1.00 by construction; vanilla baselines vary by approximately ±0.05).
- **Downstream users** can inspect the corpus distribution before committing to download the full 1.4 GB release.

## Provenance

Each file in this directory originates from a public GitHub repository under a permissive licence (MIT, Apache-2.0, BSD, CC0, Unlicense, ISC, MPL-2.0, 0BSD). The source slug (`<owner>__<repo>`) has been stripped from the filename and replaced with `sample-NNNN-<family>.md` to remove identifying information while keeping uniqueness.

## Scrubbing applied

Every file in this directory passed through the pipeline documented in [`../DATASHEET.md`](../DATASHEET.md):

1. License gate (per-repository).
2. Secret scan with `detect-secrets`, `gitleaks`, and `trufflehog` (each positive hit drops the file).
3. PII redaction: emails, GitHub @handles, internal hostnames, IP addresses, and bearer-token-shaped strings are replaced with `<REDACTED_*>` placeholders. YAML/TOML lines matching `author:`, `email:`, etc. are dropped entirely.

The total number of redactions applied in this sample is reported in [`manifest.json`](manifest.json) (591 across 105 files).

## Manifest

[`manifest.json`](manifest.json) records, for each file in the sample:

- `name`: the in-sample filename (anonymized).
- `family`: `agents.md`, `claude.md`, `cursorrules`, `copilot`, `system-prompt`, or `other`.
- `chars`: post-scrub length.
- `redactions`: number of replacements applied during scrubbing.

It also records the per-stratum count and the drop reasons recorded during sampling.

## Reporting an issue

If you find a residual secret, identifiable information, or your own content in this sample and would like it removed, please open a [data removal request](../../.github/ISSUE_TEMPLATE/data-removal-request.yml). All requests are processed within seven days; the sample is rebuilt with the opt-out list applied on a daily schedule.
